# CVI 0.1 Novelty Matrix

**Rule:** novelty is not assumed because the vocabulary or packaging is different.

| CVI element | Existing precedent | Current CVI position | Novelty status |
|---|---|---|---|
| Static performance is insufficient for broad intelligence claims | Chollet; dynamic/robust evaluation traditions | Adopt as motivation | **NOT NOVEL** |
| External feedback can improve outputs | Reflexion, CRITIC, Self-Debugging and many others | Treat as experimentally testable mechanism | **NOT NOVEL** |
| Private self-refinement can improve outputs | Self-Refine and related work | Required competing explanation/control | **NOT NOVEL** |
| Tool execution can improve correction | Self-Debugging, CRITIC, agent benchmarks | Must separate tool effect from feedback-contingency effect | **NOT NOVEL** |
| Hidden/external scoring | SWE-bench, RE-Bench, interactive benchmarks, standard testing | Required verification pattern when applicable | **NOT NOVEL** |
| Transfer to changed conditions | ScienceWorld, WILDS, generalisation literature | Required when the claim includes reusable correction | **NOT NOVEL** |
| Sham/non-contingent feedback to isolate contingency | Standard experimental-control logic | Elevated to a first-class CVI control after KILLBOX | **SYNTHESIS/APPLICATION; novelty UNRESOLVED** |
| Tool parity across causal-feedback arms | Standard ablation/fair-comparison logic | Explicit protocol requirement | **SYNTHESIS; NOT CLAIMED NOVEL** |
| Retention boundary with declared state persistence | Continual learning, memory/agent research | Explicitly separates in-context correction from retained correction | **SYNTHESIS; novelty UNRESOLVED** |
| Measurement vector rather than one “intelligence” scalar | Standard multi-metric evaluation | Replaces original metaphorical scalar framing | **NOT NOVEL AS METHOD** |
| OBSERVED / INFERRED / UNRESOLVED reporting | Scientific/epistemic discipline generally | Mandatory reporting convention | **NOT NOVEL** |
| Full chain on the same bounded capability: intervention → correction → retention → structural transfer → independent verification → confound disclosure | Strong overlap exists piecemeal across multiple fields | Candidate distinctive protocol packaging | **UNRESOLVED** |
| “Causally Verified Intelligence” as a universal new type of intelligence | No support established | Current protocol does not make this claim | **ABANDONED / UNSUPPORTED** |
| Original CVI algebra as validated measurement equations | No validation in supplied evidence | Preserved only as historical conceptual provenance | **UNSUPPORTED AS MEASUREMENT** |

## Current defensible novelty statement

Do **not** publish:

> We invented causal AI evaluation.

Do **not** publish:

> CVI is a proven new theory of intelligence.

A defensible current statement is:

> **CVI 0.1 is a provisional synthesis and experimental protocol for credentialing bounded AI capability claims across controlled correction, retention, transfer, independent verification, and explicit competing-explanation tests. Individual ingredients have substantial precedent; the distinctiveness of the full protocol remains an open research question.**

## What would move this from UNRESOLVED

A serious novelty assessment would require:

1. systematic database searches across AI evaluation, causal experimentation, adaptive systems, continual learning, psychometrics, and human-computer interaction;
2. backward/forward citation tracing from the closest protocols;
3. explicit comparison at the level of experimental requirements, not titles;
4. review by domain researchers who can identify missed literatures;
5. willingness to reduce the novelty claim if a close predecessor is found.
