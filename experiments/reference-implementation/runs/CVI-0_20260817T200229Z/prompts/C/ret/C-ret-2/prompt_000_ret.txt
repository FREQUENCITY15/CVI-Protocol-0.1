Attempt each of the following tasks ONE time. Write one OrderMachine program per task. You will receive no feedback.


## Task A-01
Read registers a and b. Apply SWIZZLE to the pair (a, b). Take the value that SWIZZLE produces and multiply it by 2. Output the result.
Worked examples (inputs -> expected output):
  case 1: inputs {"registers": {"a": 175, "b": 106}, "queue": []} -> [210]
  case 2: inputs {"registers": {"a": 71, "b": 38}, "queue": []} -> [74]
  case 3: inputs {"registers": {"a": 3, "b": 62}, "queue": []} -> [122]
  case 4: inputs {"registers": {"a": 243, "b": 43}, "queue": []} -> [84]

## Task A-02

## Task A-04
Read registers a and b. Use SPLICE on the pair (a, b). SPLICE puts three numbers onto the queue. Move the entire queue to the output, front to back.
Worked examples (inputs -> expected output):
  case 1: inputs {"registers": {"a": 44, "b": 77}, "queue": []} -> [4, 7, 7]
  case 2: inputs {"registers": {"a": 176, "b": 134}, "queue": []} -> [17, 13, 4]
  case 3: inputs {"registers": {"a": 20, "b": 114}, "queue": []} -> [2, 11, 4]
  case 4: inputs {"registers": {"a": 236, "b": 24}, "queue": []} -> [23, 2, 4]
