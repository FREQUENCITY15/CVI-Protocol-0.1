Attempt each of the following tasks ONE time. Write one OrderMachine program per task. You will receive no feedback.


## Task C-01
Read registers a and b. Apply SWIZZLE to the pair (a, b). Take the value that SWIZZLE produces and multiply it by 3. Output the result.
Worked examples (inputs -> expected output):
  case 1: inputs {"registers": {"a": 188, "b": 50}, "queue": []} -> [147]
  case 2: inputs {"registers": {"a": 171, "b": 10}, "queue": []} -> [27]
  case 3: inputs {"registers": {"a": 214, "b": 21}, "queue": []} -> [60]
  case 4: inputs {"registers": {"a": 63, "b": 20}, "queue": []} -> [57]
