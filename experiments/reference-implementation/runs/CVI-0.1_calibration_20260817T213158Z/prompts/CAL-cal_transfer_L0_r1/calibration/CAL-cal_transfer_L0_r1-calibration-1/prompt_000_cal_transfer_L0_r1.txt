Attempt each of the following tasks ONE time. Write one OrderMachine program per task. You will receive no feedback.


## Task B-S1-01
Start from the registers a and b. Use the SWIZZLE operator on these two registers. Whatever number the operator yields, scale it by a factor of 2, and emit that final number.
Worked examples (inputs -> expected output):
  case 1: inputs {"registers": {"a": 252, "b": 72}, "queue": []} -> [142]
  case 2: inputs {"registers": {"a": 162, "b": 45}, "queue": []} -> [88]
  case 3: inputs {"registers": {"a": 180, "b": 29}, "queue": []} -> [56]
  case 4: inputs {"registers": {"a": 109, "b": 102}, "queue": []} -> [202]

## Task B-S1-02
Consider the single register a. Run the MIRROR operation over it, then raise the number it hands back by 2. That increased number is what you should output.
Worked examples (inputs -> expected output):
  case 1: inputs {"registers": {"a": 86}, "queue": []} -> [109]
  case 2: inputs {"registers": {"a": 45}, "queue": []} -> [183]
  case 3: inputs {"registers": {"a": 214}, "queue": []} -> [110]
  case 4: inputs {"registers": {"a": 136}, "queue": []} -> [20]

## Task B-S2-01
